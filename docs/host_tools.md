# Host tools

Everything runs from the repository root:
- **Python:** a virtual environment in `.venv_local`, created with `python3 -m venv .venv_local && .venv_local/bin/pip install -r requirements.txt`.
- **MATLAB:** add `matlab/` (and `tests/` for the tests) to the path.

| Module | Purpose |
|---|---|
| `capture/esp_sdr.py` | serial client for ESP-SDR/ESPsoup: SYNC, INFO/CAPS/LIMITS, FREQ, GAIN, DCCAL, CAP/CAPT bursts, `ssb_stream()` for SSBDET, RTS reset |
| `capture/capture_bursts.py` | command line: `info`, `gain-scan`, `capture`, `ssb-stream` |
| `capture/session.py` | session format, reader, `SsbRecorder` |
| `capture/nr_ssb.py` | the NR SSB receiver in NumPy |
| `capture/nr_pbch_tables.py` | polar tables of the PBCH, generated by `matlab/export_pbch_tables.m` |
| `capture/ssb_live.py` | live view (board or replay) |
| `capture/band_survey.py` | stitched spectrum of band surveys, occupied stretches |
| `capture/session_spectrum.py` | averaged spectrum of sessions with SSB markers |
| `matlab/ssb_detect.m`, `detect_session.m` | reference detector for one burst / a whole session |

## Captures

```bash
.venv_local/bin/python -m capture.capture_bursts info --port /dev/ttyACM0
.venv_local/bin/python -m capture.capture_bursts gain-scan --port /dev/ttyACM0 --freq 2131 --rate 20 --bits 8
.venv_local/bin/python -m capture.capture_bursts capture --port /dev/ttyACM0 --freq 2131 --rate 20 --bits 10 \
    --gain auto --count 300 --label n1_2131 --note "board antenna, indoors"
.venv_local/bin/python -m capture.capture_bursts ssb-stream --port /dev/ttyACM0 --freq 2131 --ssb 2125.45 \
    --nid2 0 --cfo 12000 --duration 30                                     # on-chip SSB detection
```

**Options:**
- **`--freq`** is the LO in whole MHz. Several values capture round robin, `--per-freq` bursts each, which makes a band survey.
- **`--gain auto`** scans the gain indices and takes the highest without clipping; give a number to fix it.
- **`--rate`** is in MS/s (80, 40, 20, 10, 8, 4).
- **`--bits`** is 8 (CAP16) or 10 (CAP20).
- **`--count` / `--duration`** say when to stop.
- **`--label` and `--note`** go into the session.

### Session format

A session is a folder `data/<YYYYmmdd_HHMMSS>_<label>/`:
- **`session.json`:** the device's answers (INFO, CAPS, LIMITS, VERSION, FWOPT) and the settings.
- **`bursts.bin`:** all payloads as received, appended.
- **`bursts.jsonl`:** one line per burst: byte offset and length, format, `n`, `fs`, `freq_mhz`, gain, `t0_us` (time of the first sample, µs since boot), CRC result, temperature, and for SSBDET cuts the `ssb_*` fields (`ssb_pss_in_cut`, `ssb_cfo_hz`, `ssb_nid2`, `ssb_stat`, `ssb_mode`).
- **`ssb_events.jsonl`** (SSBDET only): every frame, also the header-only ones, with `t_pss_us`.

**Readers:**
- Python: `capture.session.load_session(folder)` → `(meta, records, iq_list)`.
- MATLAB: `esp_load_session(folder, 'FreqMHz', ..., 'Index', ..., 'MetaOnly', ...)`.

Both negate Q as the firmware sends −Q.

## Live view

```bash
.venv_local/bin/python -m capture.ssb_live --port /dev/ttyACM0 --freq 2131 --ssb 2125.45          # scans for the cell
.venv_local/bin/python -m capture.ssb_live --port /dev/ttyACM0 --freq 2670 --ssb 2667.75 --nid2 2 --cfo 8000 --record
.venv_local/bin/python -m capture.ssb_live --replay samples/ssbdet_pci165_150cuts [--speed 0]
.venv_local/bin/python -m capture.ssb_live --replay data/<plain burst session> --ssb 2125.45    # PSS search on the PC
```

**Live mode:**
1. Auto gain (or `--gain`).
2. Without `--nid2`/`--cfo`: a scan with up to `--scan-bursts` full bursts at the SSB frequency over all N_ID2 and ±30 kHz, keeping the cell with the most decoded MIBs.
3. SSBDET with that cell.

Every cut is decoded in a separate process. It is also tried with the other two N_ID2 at the same PSS position, so co-sited sectors show up. Such a cell is kept only with a decoded MIB, or with an SSS statistic of at least 18. `--record` stores the session like `ssb-stream`.

**Recovery:**
- If the board drops off USB or stops answering, the view reopens the port (by its Espressif ID if the name changed), resets the board through RTS if needed, and restarts SSBDET with the last CFO.
- If no line comes for 15 s, it sends STOP. An END reply means the board is alive but sees no SSB; after two such runs it scans again.
- The board's clock restarts at 0 on a reset: the time axis is continued, and the timing fit starts again.

**Panels:**
- **SSB resource grid:** mean of the last 25 SSBs, 240 subcarriers × 4 symbols, dB over the noise.
- **PBCH constellation:** MMSE-equalised. After a decoded MIB, points are coloured by the symbol that was sent; the big dots are the mean per colour.
- **Latest cut:** power with the four OFDM symbols marked.
- **Channel estimate.**
- **Over time:**
  - CFO of the decoded SSBs, with the chip's own estimate and the CFO the measured clock rate implies;
  - SFN-anchored frame timing with a quadratic clock fit, plus the clock error now (ppm) and its change per minute;
  - SNR (o MIB decoded, x failed).
- **Side panels:** stream counters (including board losses), the latest MIB fields, the cell table, a log.

**Controls:**
- Click a row of the cell table to show or hide a PCI, double-click to show only it, "Show all" to undo; `--hide 165` starts with PCIs hidden.
- "Save PNG" writes the figure to `results/`.
- `--quit-after S --snapshot x.png` saves the figure and a window grab, then quits (used by the tests on a virtual display).

## Band survey

```bash
.venv_local/bin/python -m capture.capture_bursts capture --port /dev/ttyACM0 --freq $(seq 2175 15 2715) \
    --per-freq 60 --count 2220 --rate 20 --bits 8 --gain 72 --label survey_2175_2715
.venv_local/bin/python -m capture.band_survey data/<survey> [data/<survey2>] --out results/band_survey.png \
    [--ssb results/<survey>_ssb_<tag>.csv]
```

`band_survey` averages the spectrum per LO, keeps the central ±8 MHz, stitches everything onto one axis with approximate band allocations, and prints the occupied stretches. NR cells hardly show in an averaged spectrum (an idle cell sends almost only its SSBs). So search the survey for SSBs with the MATLAB detector, centring the CFO window on the board's crystal error at the time (see [hardware.md](hardware.md)):

```matlab
addpath('matlab');
detect_session('data/<survey>', 'CFOCenter', -7.1e3, 'CFOMax', 10e3, 'Tag', 'scs15');                 % 15 kHz, L_max 4
detect_session('data/<survey>', 'SubcarrierSpacing', 30, 'Lmax', 8, 'CFOCenter', -7.1e3, 'Tag', 'scs30');
detect_session('data/<survey>', 'FreqMHz', [2655 2670], 'Tag', 'n7');                                 % only some LOs
```

`detect_session` writes `results/<session>[_<tag>]_ssb.{md,csv,mat}`:
- one CSV row per PSS peak: PCI, SSB index, CFO, SNR, MIB, SFN, PSS time and frame time;
- a summary by cell, and SSS statistics summed over bursts for cells too weak for one burst.

It loads the bursts in blocks of 200, so large surveys fit in memory. Use `CFOCenter` = −ppm × f.

## The NumPy receiver

```python
from capture import nr_ssb as nr
from capture.session import load_session
meta, recs, iq = load_session("samples/ssbdet_pci165_150cuts")
r = recs[0]
out = nr.receive(iq[0], r["fs"], r["ssb_pss_in_cut"], f_ssb=2125.45e6, f_lo=2131e6,
                 cfo=r["ssb_cfo_hz"], nid2=r["ssb_nid2"], t_first_us=r["t0_us"])
print(out["pci"], out["issb"], out["mib"], out["cfo"], out["snr_db"], out["t_frame_us"])
# plain bursts (no on-chip detection): find the PSS first
peaks = nr.pss_search(burst_iq, 20e6, offset_hz=2125.45e6 - 2131e6)   # [{"t_pss", "nid2", "stat", "cfo"}, ...]
```

`receive()` returns:
- the 240 × 4 grid, the channel and the MMSE-equalised PBCH symbols;
- the PCI, SSB index and half frame, the MIB (a dict, or `None`);
- the CFO (Hz), SNR per resource element, PSS time and frame start (µs).

It supports 15 kHz SSBs with L_max 4; for 30 kHz or L_max 8 use the MATLAB detector.

## MATLAB tools

| Function | Purpose |
|---|---|
| `ssb_detect(x, fs, 'fLO', f, ...)` | one burst: GSCN search, PSS over CFO hypotheses, SSS, CFO refinement with the TS 38.211 symbol phase removed (`SymbolPhase`), DM-RS, PBCH, BCH; options `fSSB`, `SubcarrierSpacing`, `Lmax`, `CFOCenter`, `CFOMax`, `KeepTrace` |
| `detect_session(folder, ...)` | the above over a session, summary by cell |
| `sim_ssb_detection` | Monte Carlo of detection and MIB decoding against SNR (AWGN, C5 receiver model) |
| `ssb_test_waveform`, `c5_rx_model` | SSB-only test signal with ground truth (`CarrierFrequency` adds the RF symbol phase a real gNB applies); simulated C5 capture |
| `make_n310_ssb_waveform` | SSB and CW files for a cabled test with a USRP (sensitivity in dBm). **Cable and attenuators only.** |
| `export_pbch_tables` | the polar tables for `capture/nr_pbch_tables.py` and the test vectors in `tests/fixtures/nr_pbch_vectors.json` |

Never pipe `matlab -batch` output: recent MathWorks service hosts keep the pipe open. Redirect to a file instead: `matlab -batch "..." > log 2>&1 < /dev/null`.

## Tests

```bash
.venv_local/bin/python -m unittest discover -s tests -t .           # Python: 25 tests
SNIFFER_SAMPLES_ONLY=1 .venv_local/bin/python -m unittest discover -s tests -t .   # as a fresh clone would
matlab -batch "addpath('matlab','tests'); test_matlab_loader; test_ssb_chain; test_detect_session" > logs/tests.log 2>&1 < /dev/null
```

**What the tests cover:**
- The capture client against a fake board on a pseudo-terminal, including SSBDET.
- The NumPy receiver bit for bit against 5G Toolbox vectors, and against MATLAB's results on recorded cuts.
- The firmware DSP compiled for the PC.
- The live view's decoder, clock fit, PCI selection and a full replay on a virtual display (`xvfb-run`).
- In MATLAB, the detector end to end on simulated captures.

Tests that need captures use `samples/` when `data/` is absent.
